在宅医療DX
失敗しない自動化の手順書

医療法人おひさま会が、自院の事務負担を減らすために現場で重ねてきた手順です。
院内での共有や検討資料として、自由にご活用ください。

1. 最初に決めること

DXの目的は、システムを増やすことではありません。患者さんと向き合う時間を増やすことです。

そのために、まず次の線引きから始めました。

  • 人と人が向き合う仕事（診察、説明、相談）には、AIを入れない
  • 人がやらなくてよい仕事（仕分け、転記、下ごしらえ）から仕組みにする
  • 完成の責任は、最後まで人が持つ

2. 最初に手をつける3つ

全部を一度に作りません。効果が早く、医療判断から遠いものから始めます。

手順 1

FAX・紙の仕分けを仕組みにする

宛先や書類の種類を調べる時間は、一日の中で大きく積もります。ここを仕組み化すると、事務の流れが大きく変わります。

おひさま会では月約5,000枚を対象に、1枚あたり数秒で仕分けの下ごしらえを行い、処理費用は約0.1円/枚です。確信度が低いものは人が確認します。

手順 2

問合せを「止めて、分けて、渡す」

電話応対そのものをボットに置き換えることはしません。内容の整理と担当への通知を仕組みにし、返信や判断は人が行います。

手順 3

定期書類は下ごしらえだけ自動化する

指示書や情報提供書は、前回の引用と下書き（下ごしらえ）まで。完成ボタンは医師・担当者が押します。

3. 安全の3原則（短縮版）

  1. 事務のAIと、医療の判断を分ける
  2. 人の確認を、必要なところに残す（止める道は残す）
  3. 自信が低いデータは「要確認」へ回す

詳しくは 安全の考え方 を参照してください。

4. 自院で進めるときの順番

  1. いま一番時間を奪っている非対人業務を1つ書き出す
  2. 既存の電子カルテや複合機を、買い替えずに活かせないか確認する
  3. 「人が確認する地点」を先に決める
  4. 小さく本番で試し、実際の件数と詰まりを1ヶ月観察する
  5. 現場が慣れてから次の業務へ広げる（最初から全体最適を狙わない）
このページの数字は、おひさま会5拠点の運用実績です。他院で同じ結果になる保証はありません。試算が必要な場合は、個別にご相談ください。

5. 次の一歩

加算（在宅医療DX情報活用加算）を調べて来られた方も、この手順書の対象です。点数や届出は国の資料をご確認ください。加算のあとも残る日常の事務を、内製で減らしていく順番がここにあります。

現場の見学や、自院の状況に合わせた具体的なご相談も受け付けています。まずは現場でいま困っていることからお聞かせください。

加算と現場の違いの整理は、在宅医療DXの2つの意味にあります。
