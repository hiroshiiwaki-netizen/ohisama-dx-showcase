GUIDE

在宅医療DX
失敗しない自動化の手順書

医療法人おひさま会が、自院の事務負荷を減らすために守ってきた順番です。印刷して社内共有しても構いません。

1. 最初に決めること

DXの目的は、システムを増やすことではありません。患者さんと向き合う時間を増やすことです。

そのために、次の線引きを先にします。

  • 人と人が向き合う仕事（診察、説明、相談）には、AIを入れない
  • 人がやらなくてよい仕事（仕分け、転記、下ごしらえ）から自動化する
  • 完成の責任は、最後まで人が持つ

2. 最初に手をつける3つ

全部を一度に作りません。効果が早く、医療判断から遠いものから始めます。

手順 1

FAX・紙の仕分けを仕組みにする

宛先と書類の種類を人が調べる時間が、いちばん積もります。ここを先に減らすと、事務の一日が変わります。

おひさま会では月約5,000枚を対象に、1枚あたり数秒オーダーまで圧縮し、処理費用は約0.1円/枚です。確信度が低いものは人が確認します。

手順 2

問合せを「止めて、分けて、渡す」

電話そのものをボットに置き換えません。内容の整理と担当への通知を仕組みにし、返信は人が行います。

手順 3

定期書類は下ごしらえだけ自動化する

指示書や情報提供書は、引用と下書きまで。完成ボタンは医師・担当者が押します。

3. 安全の3原則（短縮版）

  1. 事務のAIと、医療の判断を分ける
  2. 人の確認を挟んでからカルテへ載せる
  3. 自信が低いデータは「要確認」へ倒す

詳しくは 安全の考え方 を参照してください。

4. 自院で進めるときの順番

  1. いまいちばん時間を奪っている非対人業務を1つ書く
  2. 既存の電子カルテや複合機を、捨てずに使えるかを見る
  3. 「人が確認する地点」を先に決める
  4. 小さく本番で試し、件数と詰まりを1ヶ月見る
  5. 次の業務に広げる。最初から全体最適を狙わない
このページの数字は、おひさま会5拠点の運用実績です。他院で同じ結果になる保証はありません。試算が必要な場合は、個別にご相談ください。

5. 次の一歩

加算（在宅医療DX情報活用加算）を調べて来た方も、この手順書の対象です。点数は国の資料へ。加算のあと残る事務を、内製で減らす順番がここにあります。

読み物で足りなければ、稼働している現場の見学か、自院の状況に合わせた対話ができます。先に、現場の困りごとを伺います。

加算と現場の違いの整理は、在宅医療DXの2つの意味にあります。
